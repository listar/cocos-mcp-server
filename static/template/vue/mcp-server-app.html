首次连接 · 4 步开始

  1. 打开「服务器」，确认端口与设置，点击「启动服务器」。
  2. 复制 HTTP URL 和访问令牌。地址形如 http://127.0.0.1:端口/mcp。
  3. 在支持 Streamable HTTP 的 MCP 客户端中添加服务器，并设置请求头 Authorization: Bearer <访问令牌>。Codex、Claude Code、Cursor 的具体配置入口以各客户端为准。
  4. 在「工具管理」启用任务需要的工具，让 AI 先查询当前场景，再执行修改并验证。

服务器运行时才能连接。无需为 MCP 开启 REST API；配置通常保存在当前项目的 settings 目录中。

推荐的协作方式

先说明目标与限制，例如：“先查看当前 Canvas 层级，再创建一个静态设置面板，保留已有节点，并查询结果确认布局。”

单个、明确、固定的 UI 优先使用节点层级与组件；批量、数据驱动或运行时动态界面适合脚本、组件与 Prefab 模板。可以在服务器设置中调整「静态 UI 层级优先」。

编辑前保存项目，复杂修改分步进行。某些编辑器命令只代表已派发，需后续查询确认完成。

安全与访问边界

  • 仅监听本机 127.0.0.1；客户端通过 Token 鉴权。请勿把令牌贴入截图、日志或共享文档。
  • 浏览器来源默认不放行，需要时填写明确的允许来源。
  • 高风险工具默认关闭，启用与实际调用确认是两个独立步骤；调用必须提供 confirm: true。
  • 内置参数校验、请求大小、并发、会话及执行超时限制。超时不表示编辑器操作已撤销，重试前先查询结果。

遇到问题时

服务器启动失败
查看服务器状态提示；端口被占用时换一个端口并保存。
客户端无法连接或鉴权失败
确认服务器正在运行、地址以 /mcp 结尾，且请求头使用当前项目的访问令牌。
看不到工具或更改未显示
检查工具是否启用，清除工具页筛选；必要时让客户端刷新工具列表或重新连接。
调用失败或执行超时
检查目标场景是否就绪、参数及确认字段是否完整。先核对编辑器实际状态，再决定是否重试。

已验证编辑器版本为 3.8.8；其他版本需另行验证兼容性。
